# IGCSE simulations and tools

The GitHub Pages site collects seven public ConceptOrbit resources for Cambridge IGCSE Physics (0625), Mathematics (0580), and Computer Science (0478). Each entry has an official ConceptOrbit embed and a direct link to its full resource page. The original five-minute Balance the Beam activity and worked answers are also included.

[Open the resource collection](https://conceptorbit.github.io/)

Open `index.html` to preview the catalog locally. The interactive resources are hosted by ConceptOrbit and require an internet connection. GitHub Pages deploys from `main` and `/ (root)`.

[ConceptOrbit](https://www.conceptorbit.com/)
